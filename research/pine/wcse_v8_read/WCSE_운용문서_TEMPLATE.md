## 3. 운용 룰 (라이브)
1. **진입**: WCSE 암드 → 스윕+복귀 트리거 + btc_bias 게이트 통과 시에만. 수동 재량 진입 금지.
2. **사이즈**: 기본 리스크 ____% / 거래. *(v8 합류 보조 시그널 동시 발생 시 1.5x — 거래 로그 검증 통과 후에만 활성화. 검증: 로그에서 v8 동시발생 거래의 기대값(R)이 단독 대비 ≥ +0.2R)*
3. **무효화**: 구조 역전·rITH/rITL 침범 → 즉시 청산 + 쿨다운 ____봉 같은 방향 금지.
4. **TP**: 50/30/20 사다리, TP1 후 본절. 러너 임의 조기청산 금지.
5. **점검 주기**: 월 1회 — 최근 3개월 라이브 성과 vs OOS 기대치 비교, PF가 OOS의 50% 미만 2개월 연속 시 운용 중단·재검증.

## 4. TF별 참고 (3번 메뉴 진행 시)
- 1h/4h/1d는 상관 표본 — "합산 통계"가 아니라 **TF 강건성 검사**로 해석.
- TF가 내려갈수록: swLen↓(5~8), 수수료 비중↑ → rrMin을 올려야 기대값 유지.
- 킬존 게이트는 1h 이하에서만 의미 검증.
