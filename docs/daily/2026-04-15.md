- .gitignore 정리 (inventory, tfstate, pem, CLAUDE.md)
- git 추적 해제 (git rm --cached)

### 트러블슈팅

- inventory 확장자 불일치 (.yml vs .yaml) → ansible.cfg 경로 수정
- Docker/kubectl 설치 시도 → K3s에 내장, 별도 설치 불필요
- EC2 메모리 부족 (95% 사용) → apt 멈춤, SSH 접속 불가
- IO Wait 82% → swap 없어서 디스크에 계속 접근
- user_data `#!/bin/bash` 앞 공백 → 스크립트 미실행
- EC2 재부팅 불가 → 중지 후 시작으로 해결 (IP 변경됨)
- kubeconfig x509 에러 → `--tls-san` 옵션 필요 (퍼블릭 IP 인증서 포함)
- scp Permission denied → sudo cp로 /tmp에 복사 후 가져오기

### 배운 것

- Terraform = 인프라 생성/삭제, Ansible = 서버 내부 설정 (역할 분리)
- Ansible 멱등성: 두 번 실행해도 changed=0 (이미 설치된 건 건너뜀)
- K3s vs K8s: K3s는 512MB면 가능, K8s는 4GB+ 필요
- K3s는 containerd 내장 → Docker 설치 불필요 (메모리 절약)
- t3.micro (1GB)에서 swap 없이 K3s 못 돌림
- `become: true` → sudo 권한 필요한 작업에 필수
- `state: present` → "설치되어 있어야 한다" (멱등성)
- `creates:` → 이 파일 있으면 실행 건너뜀 (멱등성)
- `register` + `debug` → 명령어 결과를 변수에 저장 후 출력
