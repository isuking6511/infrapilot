## 2) 심볼 필터링 정책: `fetch_symbols(min_volume=5_000_000)`

```python
if not (symbol.endswith("/USDT") or symbol.endswith("/USDT:USDT")):
    continue
if float(ticker.get("quoteVolume") or 0) >= min_volume:
    symbols.append(symbol)
```

### 구현 포인트

1. **마켓 타입 필터**
   - `"/USDT"` 또는 `"/USDT:USDT"`만 허용
   - 원화마켓/기타 통화쌍/비선호 계약을 초기에 배제

2. **유동성 필터**
   - `quoteVolume` 기준 최소 거래대금 적용
   - 기본 임계치 `5,000,000`으로 저유동성 심볼 노이즈 감소

3. **결측 대응**
   - `ticker.get("quoteVolume") or 0`으로 null/미기재 케이스 방어

### 파이프라인 관점 효과

- 이후 AI 분석 단계에 들어가는 심볼 수가 일정해지고, 지나치게 얇은 마켓을 초기에 걸러 분석 품질을 안정화함

## 3) 캔들 정규화: `fetch_ohlcv(symbol, timeframe="15m", limit=200)`

```python
raw = exchange.fetch_ohlcv(symbol, timeframe, limit=limit)
return [
    {
        "timestamp": row[0],
        "open": row[1],
        "high": row[2],
        "low": row[3],
        "close": row[4],
        "volume": row[5],
    }
    for row in raw
]
```

### 왜 이 변환이 핵심인가

- ccxt 원본은 위치 기반 배열(`row[0]`, `row[1]`...)이라 후속 단계 가독성이 낮음
- dict 키(`open`, `close`)로 변환해 저장 계층(DB)과 분석 계층(AI Agent)에서 공통 계약으로 재사용 가능
- `timeframe`, `limit` 파라미터로 테스트/운영 환경에서 같은 함수 인터페이스 유지
